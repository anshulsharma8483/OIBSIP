
# BMI Calculator — Oasis Infobyte Internship

## Overview
A Python command-line application that calculates
Body Mass Index (BMI) using weight and height.

## Features
- Calculates BMI using weight in kilograms and height in metres.
- Displays BMI rounded to two decimal places.
- Classifies results into standard adult BMI categories.
- Validates numeric and positive inputs.
- Supports repeated calculations in one session.

## Technology Used
- Python 3
- Built-in Python libraries only

## Formula
BMI = Weight (kg) / Height (m)^2

## How to Run
1. Install Python 3.
2. Open a terminal in this project folder.
3. Run:

   python bmi_calculator.py

## Testing
Tested with valid inputs, non-numeric values,
zero values, and negative values.

## Disclaimer
This project is for educational purposes only.
BMI is a screening measure, not a medical diagnosis.
